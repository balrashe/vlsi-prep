Claude Code mods are live, and most people haven't touched them yet 🧩

A mod is a small JavaScript or TypeScript plugin that runs inside Claude Code. It can message your other sessions, send a request to a different model, and draw its own panes with tabs and buttons. Mods are on by default in Claude Code 2.1.287 and later.

Heads up: a mod runs with your permissions and isn't sandboxed. It can read your files and API keys, so only install ones you trust.
