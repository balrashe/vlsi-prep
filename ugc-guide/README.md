# Tech UGC Starter Guide — handoff package

## How to use

1. Put this folder in a directory Claude Code can see.
2. Make sure the two skill files are available at:
   - `skills/apple-design/SKILL.md`
   - `skills/frontend-design/SKILL.md`
3. Drop your three images into `assets/` using the exact filenames below.
4. Open Claude Code in this folder and paste the entire contents of `BUILD-PROMPT.md` as your first message.

## Assets you need to add

| File | Page | Notes |
|---|---|---|
| `assets/views-grid.png` | 2 | Video thumbnails with view counts from the new UGC account |
| `assets/payments.png` | 7 | Payment receipts. **Blur every payer name before exporting.** Used as-is. |
| `assets/discord.png` | 9 | Optional. Server screenshot. |

## Files

- `BUILD-PROMPT.md` — paste this into Claude Code
- `COPY.md` — locked copy for all 9 pages, do not let it get rewritten
- `assets/` — drop images here

## Two open decisions

1. **No date on the cover.** Dating it makes it stale in four months and this guide should run all year.
2. **The 30 days claim** on the cover is the only unbacked claim in the document. If most creators take longer, cut that stat and run with two.
